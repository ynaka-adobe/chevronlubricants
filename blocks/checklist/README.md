# checklist

Custom **checklist** block. Purpose: a titled list of benefits or features with check marks or bullets, optionally next to an image, another list or a button. Also used for the image + checklist panel on the ISOCLEAN Certified Lubricants Program page.

## Authoring (Document Authoring)

Model: `standalone`

Block table: one or more rows of 1–2 cells. Each cell is free content:

- a list: an optional heading (title), then a bulleted list; start an item with bold text for its title, then a line break and the item text
- an image (optionally linked) with an optional caption paragraph
- a button (a bold link)
- text paragraphs

Two cells in a row sit side by side on screens 600px and wider. A row whose cells are all images (with captions) shows them as white cards.

## Supported variations

- `check`: check marks (default marker is a round bullet)
- `bullet`: round bullets
- `grey`: light grey panel behind lists and text
