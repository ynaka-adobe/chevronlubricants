# quote-testimonial

Custom **quote** block. Purpose: customer testimonial.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: up to 5 rows: [portrait] [title] [quotation] [attribution] [CTA link].

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Notes

Up to 5 single-cell rows: [optional portrait image] [optional title] [quotation paragraph(s)] [attribution: name line, role/location line] [optional CTA link]. Rows are recognised by content. Append #_dnb to a YouTube CTA to keep it a link.
