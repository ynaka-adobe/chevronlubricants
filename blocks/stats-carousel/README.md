# stats-carousel

Custom **stats-carousel** block. Purpose: a set of statistics shown one at a time, each a value in a progress ring with a caption (for example "65%" and what it measures).

## Authoring (Document Authoring)

Model: `standalone`

Block table: one row per statistic, 2 cells: [value | caption]. A value ending in `%` (e.g. `65%`) fills the ring to that percentage; any other value is shown without an arc.

Visitors move between statistics with the previous/next buttons; the counter reads "1 of 4".

No variations.
