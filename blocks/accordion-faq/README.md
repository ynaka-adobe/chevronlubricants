# accordion-faq

Custom **accordion** block. Purpose: FAQ.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row per FAQ: [question | answer rich text].

## Supported variations

| Variation | Option class |
| --- | --- |
| Load more (first 3 items, "Load more questions" / "Hide items", "Expand all" toggle, blue icons) | `load-more` |
| Grey (light-grey column, cobalt icons; source Techron FAQs) | `grey` |
| Blue (dark-blue questions/toggle/icons, "Expand all" toggle; source industrial FAQs) | `blue` |
